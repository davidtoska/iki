# Intro
This kiosk will open a url and serve the content om a big TV.
The user will only use a remotecontroll with 6-7 buttons: up, down, power-button and a few more.
The buttons can send keyboardevents to a usb-recicer
The bow will be configured by us with a keyboard and mouse.

# Teknology
- Electron js
- Vanilla js
- Minimalistic



# Functionality
- This is a kiosk electron app - load a url
- The kiosk will run on a arch-os as a kiosk.
- Can save configuration in a file.
- Will reload the browserwindow when configuration change
